On narrow screens, scroll the diagram horizontally. Related endpoints are grouped for readability; the groups are not deployment or trust boundaries.

The complete runtime

Arrows identify callers or update senders, not inherited authority. Request responses are summarized, not drawn as a second arrow on every connection. Policy, approval and egress checks remain separate. Use the companion guide for the operator and failure paths.

Administering is not executing.

The owner-run ./turing command validates .env, operates Compose, and checks health. It does not open SQLite. The agent has no Docker control. Guided setup and engine commands choose and prove the local engine.

Consent is scoped to the work.

Delegation is experimental and off by default. Each child needs its own remote-tool consent. Continuations have no egressing tools. Stop is not rollback; deletion withdraws owned state, not vendor copies.
